# دليل النشر والتشغيل (Deployment and Operations Guide)
## نظام إدارة ورشة ميكانيكا السيارات — Workshop Management System

---

## 1. متطلبات التشغيل (System Prerequisites)

- **نظام التشغيل:** Windows 10/11 أو Windows Server أو Linux (Ubuntu 22.04+)
- **بيئة العمل:** Node.js v20.x LTS أو أحدث
- **الذاكرة:** 2GB RAM كحد أدنى (موصى بـ 4GB+)
- **مساحة التخزين:** 10GB فما فوق (بحسب حجم الصور والتقارير المرفوعة)
- **الشبكة:** شبكة محلية Wi-Fi سريعة ومستقرة تغطي باحات الورشة وغرف الإدارة والفحص.

---

## 2. خيارات النشر والتشغيل (Deployment Models)

### الخيار أ: الخادم المحلي بالورشة (Local Network / On-Premise LAN) — *الأكثر شيوعاً*
- يُنصب الخادم المركزي على جهاز كمبيوتر رئيسي بالورشة (Host PC).
- يتم ضبط IP ثابت للجهاز على الراوتر (مثال: `192.168.1.100`).
- تتصل أجهزة موظفي الاستقبال وأجهزة المحاسبين (Windows) عبر المتصفح أو تطبيق سطح المكتب بالرابط: `http://192.168.1.100:4000`.
- تتصل هواتف الفنيين (Android) بالشبكة نفسها عبر المتصفح أو التطبيق المثبت (PWA/Capacitor APK).
- **المميزات:** يعمل حتى عند انقطاع الإنترنت الخارجي عن الورشة، استجابة فائقة السرعة، استقلالية كاملة.

### الخيار ب: السيرفر السحابي (Cloud VPS)
- تشغيل الخادم على خادم سحابي (DigitalOcean, AWS, Hetzner, etc.).
- توفير شهادة أمان SSL (HTTPS & WSS).
- إمكانية وصول صاحب الورشة من أي مكان في العالم ومتابعة السيارات والإيرادات لحظياً.

---

## 3. خطوات التشغيل السريع (Quick Start)

### 1. تثبيت الحزم:
```bash
# تثبيت الاعتماديات الأساسية للمشروع كاملاً
npm run install:all
```

### 2. تجهيز قاعدة البيانات وبدء تشغيل الخادم:
```bash
# إنشاء الجداول وتشغيل الهجرات والبيانات الأساسية
npm run db:init

# بدء تشغيل الخادم والواجهة
npm run start
```

### 3. فتح النظام:
- على جهاز الويندوز: افتح المتصفح أو التطبيق على `http://localhost:5173` (أو منفذ الإنتاج `http://localhost:4000`).
- على هواتف الأندرويد: افتح متصفح الجوال واكتب عنوان الـ IP الخاص بالخادم في الورشة، ثم اضغط "إضافة إلى الشاشة الرئيسية" (Install App).

---

## 4. إعدادات البيئة (Environment Configuration)

انسخ ملف `.env.example` إلى `.env` في مجلد `backend/`:
```env
PORT=4000
NODE_ENV=production
JWT_SECRET=super_secret_jwt_key_change_in_production
DB_FILE=./data/workshop.db
UPLOAD_DIR=./uploads
CORS_ORIGIN=*
```

---

## 5. إدارة التحديثات دون فقدان البيانات (Zero-Loss Upgrades)

عند استلام تحديث جديد للنظام:
1. يتم حفظ نسخة احتياطية أولاً: `npm run backup`
2. تحديث ملفات الكود (`git pull` أو فك حزمة التحديث)
3. تشغيل ملف هجرات قاعدة البيانات: `npm run db:migrate`
4. إعادة تشغيل الخدمة: `npm run restart`
- **ملاحظة أمان:** الهجرات تستخدم أوامر إضافة الأعمدة والجداول (`ALTER TABLE ADD COLUMN`, `CREATE TABLE IF NOT EXISTS`) وتمنع قطعيًا حذف الجداول القديمة (`DROP TABLE`).
