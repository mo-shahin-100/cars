# سجل التغييرات والإصدارات (Changelog)
## نظام إدارة ورشة ميكانيكا السيارات

جميع التحديثات المهمة والترقيات في بنية النظام وقاعدة البيانات وواجهات البرمجة موثقة هنا وفق معيار Semantic Versioning (vMAJOR.MINOR.PATCH).

---

## [1.0.0] - 2026-10-03
### الميزات الأولية (Initial Release)
- **المعمارية والأساس:**
  - بناء Backend نمطي بتقنية Node.js و Express و TypeScript.
  - محرك قاعدة بيانات علائقية متكامل (SQLite WAL) يدعم القيود التكاملية والمعاملات الآمنة (ACID Transactions).
  - نظام المصادقة والصلاحيات (JWT + RBAC Middleware) مع خمسة أدوار مسبقة: Owner, Manager, Reception, Mechanic, Accountant.
  - خادم وبث WebSocket للأحداث اللحظية والمزامنة التلقائية.
- **إدارة العملاء والسيارات:**
  - إدارة ملفات العملاء مع البحث المتقدم.
  - إدارة السيارات وأرقام الهياكل (VIN) وأرقام اللوحات.
  - أرشيف انتقال الملكية بين العملاء مع حفظ التاريخ القديم للمالك السابق.
  - خط زمني تفاعلي شامل (Comprehensive Vehicle Timeline) يعرض كل الزيارات، الفحوصات، أوامر العمل، قطع الغيار، تغيير الزيوت، والفواتير في شاشة واحدة.
- **إدارة العمليات والفحص الفني:**
  - تسجيل زيارات الورشة مع قراءات العداد والشكوى الأولية.
  - أوامر الإصلاح (Work Orders) وتقسيمها لمهام عمل تفصيلية.
  - إسناد المهام لأكثر من فني مع توثيق أوقات البدء والإنجاز.
  - وحدة تشخيص الأعطال وأجهزة الكشف (OBD/Scanners) وتتبع تاريخ أكواد الأعطال (DTC Code History) عبر الزيارات.
  - قسم خاص للزيوت وسوائل الصيانة وحساب مواعيد وعداد الصيانة القادمة تلقائياً.
- **المخزون والماليات:**
  - إدارة قطع الغيار والموردين وتنبيهات وصول الحد الأدنى.
  - خصم المخزون الآمن بمعاملات مصرفية مع مفتاح عدم التكرار (Idempotency).
  - نظام الفواتير المكتمل، تفصيل الأجور والقطع، والمدفوعات المتعددة وسندات القبض الجزئية.
  - تقارير الأرباح والمصروفات والإنتاجية ومؤشرات لوحة التحكم.
- **المزامنة والملفات:**
  - طابور المزامنة دون اتصال (Offline Sync Queue).
  - رفع وإدارة الصور والملفات الفنية وربطها بالسيارات والزيارات والمهام.
  - أدوات النسخ الاحتياطي الساخن والاستعادة بدون توقف.
