# دليل النسخ الاحتياطي والاستعادة (Backup & Disaster Recovery Guide)
## نظام إدارة ورشة ميكانيكا السيارات

---

## 1. استراتيجية النسخ الاحتياطي (Backup Strategy)

لضمان عدم فقدان أي بيانات في حال عطل الجهاز المركزي أو تلف القرص الصلب:
1. **النسخ اللحظي الساخن (Online Hot Backup):**
   - استخدام واجهة النسخ الاحتياطي الخاصة بمحرك قاعدة البيانات (SQLite Online Backup API) التي تضمن إنشاء نسخة متسقة دون إيقاف الخادم أو حظر العمليات النشطة.
2. **النسخ التلقائي المجدول (Automated Scheduled Backup):**
   - وظيفة Cron دورية داخل النظام تقوم بإنشاء نسخة احتياطية يومية وأسبوعية بصيغة مضغوطة (`.sqlite.bak`).
3. **تضمين ملفات الوسائط (Media Files Backup):**
   - يتم أرشفة مجلد المرفقات والصور (`uploads/`) جنباً إلى جنب مع ملف قاعدة البيانات.

---

## 2. إجراء النسخ الاحتياطي اليدوي والمجدول

### عبر لوحة تحكم النظام (UI):
- يفتح المالك صفحة الإعدادات -> النسخ الاحتياطي -> النقر على "إنشاء نسخة احتياطية الآن".
- يقوم النظام بتوليد ملف يحمل اسم: `backup_workshop_YYYY-MM-DD_HHmmss.bak` وتنزيله فوراً.

### عبر واجهة الأوامر (CLI):
```bash
# إنشاء نسخة احتياطية فورية لقاعدة البيانات
npm run backup
```

---

## 3. إجراءات استعادة البيانات (Restore Procedure)

> [!CAUTION]
> عملية الاستعادة تستبدل البيانات الحالية ببيانات النسخة الاحتياطية. يجب أخذ نسخة احتياطية إضافية للبيانات الراهنة قبل الاستعادة.

### الخطوات:
1. إيقاف الخادم إن لزم: `npm run stop` أو عبر لوحة الإدارة.
2. استخدام أمر الاستعادة:
   ```bash
   node scripts/restore.js path/to/backup_file.bak
   ```
3. التحقق من سلامة البيانات:
   - فحص جداول العملاء والسيارات.
   - التحقق من توازن الفواتير والمدفوعات.
4. إعادة تشغيل الخادم وتأكيد جاهزية النظام.

---

## 4. اختبار التعافي من الكوارث (Disaster Recovery Verification)

- يتم إجراء اختبار استعادة شهري على بيئة تجريبية معزولة للتأكد من خلو ملفات النسخ من أي تلف.
- يُنصح برفع نسخ النسخ الاحتياطي المشفرة دورياً إلى وسيط تخزين سحابي خارجي (مثل Google Drive أو AWS S3).
