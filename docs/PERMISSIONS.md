# وثيقة الصلاحيات والأدوار (Permissions & RBAC Matrix)
## نظام إدارة ورشة ميكانيكا السيارات

---

## 1. فلسفة الأمان (Security Philosophy)

- **التطبيق الصارم على الخادم (Server-Side Enforcement):** لا يُكتفى بإخفاء الأزرار في الواجهة؛ يتم فحص الدور والصلاحية في كل مسار برمجي (API Route Middleware).
- **مبدأ الحد الأدنى من الامتيازات (Principle of Least Privilege):** كل مستخدم يُمنح فقط الصلاحيات اللازمة لإنجاز عمله.
- **تتبع العمليات الحساسة (Audit Logging):** تسجيل أي تعديل أو إلغاء مالي أو مخزني مع معرف المستخدم والتوقيت.

---

## 3. تطبيق الصلاحيات في الـ Backend (Implementation)

يتم التحقق من الصلاحيات من خلال دالة وسيطة (Middleware):
```typescript
export const requirePermission = (permission: string) => {
  return (req: Request, res: Response, next: NextFunction) => {
    const user = req.user;
    if (!user) return res.status(401).json({ error: 'غير مصرح بالدخول' });
    if (user.role === 'owner') return next(); // Owner has full access
    if (!user.permissions || !user.permissions.includes(permission)) {
      return res.status(403).json({ error: 'ليس لديك الصلاحية لتنفيذ هذا الإجراء' });
    }
    next();
  };
};
```
