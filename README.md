# نظام إدارة ورشة ميكانيكا السيارات المتكامل
### Workshop Management System (Android & Windows with Real-Time Sync)

نظام احترافي وشامل لإدارة ورش صيانة وميكانيكا وبرمجة السيارات، يدعم اللغة العربية بالكامل مع اتجاه RTL، ومصمم ليعمل على أجهزة **Windows Desktop** وهواتف **Android Mobile** في الوقت الفعلي عبر قاعدة بيانات موحدة ومزامنة عبر WebSockets.

---

## 🌟 الميزات الرئيسية للنظام

1. **التايم لاين الكامل والشامل لكل سيارة (Vehicle Timeline):**
   - سجل زمني تاريخي تفاعلي يجمع كافة الزيارات، الفحوصات، أوامر الإصلاح، أكواد الأعطال (DTC)، الزيوت المغيرّة، قطع الغيار، والصور والفواتير.
2. **فحص وتشخيص الأعطال وأجهزة الكشف (OBD & DTC History):**
   - تسجيل تقارير الفحص بالأجهزة (Autel, Launch, Bosch...).
   - تتبع تاريخ أكواد الأعطال (DTC) ومراقبة تكرارها عبر الزيارات المختلفة مع التحقق من معالجتها بفحص مسجل.
   - حفظ Freeze Frame Data واللايف داتا ورفع تقارير الـ PDF وصور شاشة الجهاز.
3. **أوامر الإصلاح وتوزيع المهام على الفنيين (Work Orders & Multi-Mechanic):**
   - إسناد مهام السيارة الواحدة لأكثر من ميكانيكي وفني كهرباء مع تسجيل ساعات العمل وأوقات البدء والإنجاز.
   - لوحة تشغيل خاصة بالميكانيكي (Android Bay Station) لتحديث المهام والتقاط الصور مباشرة.
4. **المخزون وخصم قطع الغيار الآمن (Atomic Idempotent Stock Deduction):**
   - معاملات آمنة لحركات المخزون.
   - حماية من الخصم المزدوج عبر مفتاح عدم التكرار (Idempotency Key) عند ضعف شبكة الجوال وإعادة الإرسال.
   - تنبيهات وصول القطع للحد الأدنى من الرصيد.
5. **الصيانة الدورية والزيوت (Oil & Fluids Scheduler):**
   - توثيق لزوجة الزيت (5W-30, 0W-20)، المواصفات، الفلتر، وحساب تاريخ وعداد الكيلومترات للصيانة القادمة تلقائياً.
6. **الفوترة والمدفوعات والمحاسبة (Invoices & Accounting):**
   - تفصيل أجور اليد، قطع الغيار، السوائل، والضريبة 15%.
   - دعم الدفعات الجزئية وسندات القبض الفورية مع أرصدة المتبقي.
   - تقارير الأرباح الصافية وهوامش ربح القطع والمصروفات التشغيلية.
7. **المزامنة اللحظية والعمل دون اتصال (Real-Time Sync & Offline Queue):**
   - تحديث فوري بين أجهزة الويندوز والأندرويد عبر WebSockets فور أي تعديل.
   - طابور مزامنة محلي (Offline Queue) عند انقطاع الشبكة ورفع تلقائي فور عودتها.
8. **الأمان ومصفوفة الصلاحيات (Server-Side RBAC):**
   - مصادقة عبر JWT مع التحقق الصارم من الصلاحيات على الخادم.
   - خمسة أدوار مسبقة: Owner, Manager, Reception, Mechanic, Accountant.
   - سجل تدقيق النشاط الحساس (Audit Log).
9. **النسخ الاحتياطي الساخن (Hot Online Backup):**
   - نسخ احتياطي متزامن دون إيقاف الخادم أو مقاطعة العمل.

## 🚀 طريقة التشغيل السريع (Quick Start)

### 1. تشغيل الخادم والواجهة:
```bash
# تشغيل الخادم المدمج (يشمل الـ API والواجهة وقاعدة البيانات والويب سوكيت)
cd backend
npm run dev
```

- يفتح الخادم على الرابط: `http://localhost:4000`
- منفذ WebSocket على المسار: `ws://localhost:4000/ws`
- منفذ واجهة التطوير (Vite Dev Server إن رغبت):
```bash
cd frontend
npm run dev
```

## 🔑 الحسابات التجريبية الافتراضية (Default Accounts)

| الدور (Role) | اسم المستخدم | كلمة المرور | الصلاحيات |
|:---|:---|:---|:---|
| **صاحب الورشة (Owner)** | `admin` | `admin123` | وصول كامل وغير مقيد لكافة الأقسام والماليات والنسخ الاحتياطي |
| **المدير (Manager)** | `manager` | `manager123` | توزيع المهام، إدارة العمليات والعملاء وأوامر العمل |
| **الاستقبال (Reception)** | `reception` | `reception123` | استقبال العملاء، تسجيل السيارات والزيارات |
| **ميكانيكي محركات (Mechanic)** | `ahmed` | `ahmed123` | تنفيذ المهام، تسجيل تغيير الزيوت، طلب قطع الغيار |
| **أخصائي تشخيص وبرمجة** | `mahmoud` | `mahmoud123` | فحص كمبيوتر، إدخال أكواد DTC، رفع تقارير الأجهزة |
| **المحاسب (Accountant)** | `accountant` | `accountant123` | الفواتير، سندات القبض، المصروفات، والتقارير المالية |

*(ملاحظة: تتوفر أزرار دخول سريع بنقرة واحدة في شاشة تسجيل الدخول لاختبار الصلاحيات بسهولة)*

## 🧪 تشغيل اختبارات الجودة المتكاملة (Integration Tests)

تم تضمين حزمة اختبارات تغطي كافة سيناريوهات العمل الأساسية:
```bash
cd backend
npm test
```
**نتائج الاختبارات:**
- 12 من 12 اختباراً ناجحاً تشمل: التحقق من الصلاحيات، إنشاء العملاء والسيارات، نقل الملكية مع حفظ الأرشيف، استقبال الزيارات، إسناد المهام لعدة ميكانيكيين، تقارير فحص DTC، تغيير الزيوت وحساب الصيانة القادمة، منع الخصم المزدوج للمخزون (Idempotency)، الفواتير والدفعات الجزئية، وتجميع التايم لاين.

## 📱 تشغيل التطبيق على هواتف Android

1. **الوصول المباشر عبر الشبكة المحلية (PWA):**
   - افتح متصفح الهاتف Chrome/Firefox وتوجه إلى عنوان IP الخادم في الورشة (مثال: `http://192.168.1.100:4000`).
   - اضغط على "إضافة إلى الشاشة الرئيسية" (Install App).
2. **بناء تطبيق Android أصلي عبر Capacitor:**
   - ملف الإعداد جاهز في `frontend/capacitor.config.ts`.
   ```bash
   cd frontend
   npx cap add android
   npx cap open android
   ```
